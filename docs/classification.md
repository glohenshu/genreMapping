# 毎月の分類作業

新しい連載を「ジャンル一覧」に載せるための、月1回の作業です。ページに載るのは、kintone 507（連載分類）に小分類が入っている作品だけです。507 に登録が無い作品は、毎月の自動更新でも載りません。

## いつやるか

**毎月1日〜4日**に済ませます。5日 9:00 の自動更新（「毎月の作品データ更新」）で、その月の分類がページに反映されます。

## 手順

1. **分類案を作る**
   Claude に「連載分類の月次更新をして」と頼みます（スキル「GLO連載の月1回の再分類」が動きます）。Claude が 402 と 507 を照らし合わせて、次の作品を抜き出し、小分類を判定します。
   - 新規：507 に登録が無い作品
   - 内容変更：402 のメインジャンル・ジャンル（内容）・内容紹介が、507 の控えと変わった作品

   結果は、507 に取り込める CSV（`GLO連載分類_更新_YYYYMM.csv`）で受け取ります。

2. **人が確認する**
   CSV と Claude の報告を見て、次の作品を確かめます。違っていたら CSV の小分類を直します。
   - S99（要確認）になった作品
   - 手動で直したあとに内容が変わった作品（CSV には入っていません。必要なら 507 で直接直します）
   - 402 に情報がまだ入っていない作品（今回は分類しません。402 に入ってから翌月に分類します）

3. **507 に取り込む**
   アプリ507の一覧画面 →「…」→「ファイルから読み込む」→ CSV を選びます。
   - 文字コードは UTF-8、先頭行を項目名にする
   - 「レコードを更新する」を選び、更新のキーに「レコード番号」を指定する（レコード番号が空の行は新規に追加されます）
   - 「書籍タイトル（参考・取り込み不要）」と「作品キー」の列は「取り込まない」にする

4. **記事下リンク表を作り直す**
   記事下リンク表のメニューから「リンクを作り直す」を押します。

5. **5日の自動更新のあとに確かめる**
   [`data/check.md`](../data/check.md) の「分類待ちの作品」を見ます。0件なら完了です。残っていれば、その作品を分類して取り込み、下の「すぐに反映したいとき」で更新し直します。

## すぐに反映したいとき

GitHub の「Actions」→「毎月の作品データ更新」→「Run workflow」で、いつでも作り直せます。4日までに間に合わなかったときや、月の途中で分類を直したときに使います。

## 決まりごと

- **ピックアップ企画など**：複数の作品をまとめた編集部の企画は S90、コンテストの作品集は S91、お知らせやテスト用のカテゴリは S92 にします。これらと S99（要確認）は、ページに載せません。
- **単独作品の再掲・ピックアップ版**：S90 にせず、もとの作品と同じ小分類にします。ページでは、もとの作品と1つにまとめて表示します。
- **連載準備中の作品**：分類は先に済ませておきます。第1回が公開されるまではページに載らず、公開された月の自動更新から載ります。
- **小分類（副）**：副に入れた小分類にも、同じ作品が並びます（ページでは主・副の区別は出しません）。主がしっくりこない作品は、主を内容の中心に合う小分類にし、もう一方を副に入れてください（例：ロータリークラブの作品は、主を活動の中身に合う小分類にし、「趣味・スポーツ」は副にするか空けておく）。主が S90・S91・S92・S99 の作品は、副があってもページに載りません。
- **手動で直した分類**：507 の判定区分が「手動修正」の作品は、毎月の分類作業で上書きしません。
- **小分類の一覧**：89 の小分類と、どのジャンルに入るかは [`genres_config.json`](../genres_config.json) にあります。507 の小分類（ドロップダウン）と名前をそろえてください。
