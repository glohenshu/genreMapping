# 小分類の表示設定

ページ（ジャンルから探す）に出したくない小分類を、kintone の **アプリ513「小分類の表示設定」** で隠せます。

## 表示しない小分類が決まったときの手順

かかる時間は5分ほどです。kintone で1か所直して、GitHub でボタンを1回押します。

### 0. 先に確かめること

- **隠す小分類のコード**（S01〜S89）を確かめます。小分類名は、アプリ513 の一覧に出ています。
- **その小分類にしか入っていない作品は、ページから見えなくなります。** 主か副にほかの小分類がある作品は、そちらに残ります。どの作品が見えなくなるか知りたいときは、Claude に「S○○ を表示しないにしたら、ページから消える作品を出して」と頼んでください。
- ジャンルの中の小分類をすべて隠すと、そのジャンルも目次から消えます。

### 1. kintone で「表示しない」にする

1. kintone で **アプリ513「小分類の表示設定」** を開きます（507 と同じスペースにあります）。
2. 一覧から、隠す小分類の行を探します。小分類コードの順に並んでいます。
3. その行を開き、**鉛筆マーク（編集）** を押します。
4. 「**表示**」を「**表示しない**」に変えます。
5. 「**メモ**」に、理由と日付を書いておきます（例：「2026/11/01 読者向けに不要のため」）。
6. 「**保存**」を押します。

いくつかまとめて隠すときは、全部の行を直してから次へ進んでください。

### 2. GitHub で反映する

1. https://github.com/glohenshu/genreMapping/actions/workflows/display.yml を開きます。
   （または GitHub の「Actions」→ 左の一覧の「**小分類の表示設定を反映**」）
2. 右側の「**Run workflow ▾**」を押します。
3. 小さな窓が開きます。Branch は「main」のまま、緑の「**Run workflow**」を押します。
4. 数秒後、一覧のいちばん上に新しい行が出ます。黄色の丸（実行中）が **緑のチェック** になれば完了です（1分ほど）。

※「毎月の作品データ更新」や「ページを公開」とは別のものです。間違えて押しても壊れることはありませんが、表示設定だけを反映したいときは「小分類の表示設定を反映」を使ってください。

### 3. ページで確かめる

1. https://glohenshu.github.io/genreMapping/ を開きます。
2. 隠した小分類が、目次（ジャンルを開いたときの一覧）とジャンルのページに出ていなければ完了です。
3. まだ出ているときは、**Ctrl＋F5**（Mac は ⌘＋Shift＋R）で読み込み直してください。それでも出る場合は、10分ほど待ってからもう一度見てください（ブラウザが前の表示を覚えているため）。

反映済みの一覧は [`data/display.js`](../data/display.js) でも確かめられます（`window.GLO_HIDDEN = ["S○○"]` に、隠した小分類のコードが入っていれば反映済みです）。

## 表示に戻すとき

手順 1 で「表示」を「**表示する**」に戻して保存し、手順 2・3 を同じようにやります。

## うまくいかないとき

| こんなとき | すること |
|---|---|
| 手順 2 で赤い × になった | その行を開き、「表示設定を読む」のメッセージを見てください。「シークレット … が登録されていません」なら GitHub の設定が消えています（下の「はじめに1回だけやること」の 4）。kintone の API トークンを作り直した場合も、GitHub のシークレットを新しいトークンに直す必要があります。分からないときはメッセージを Claude に貼ってください。赤い × のときはページは変わらず、前の表示のままです。 |
| 緑のチェックなのにページが変わらない | Ctrl＋F5 で読み込み直す。10分ほど待つ。`data/display.js` にコードが入っているか見る。入っていなければ、kintone で「表示しない」が保存されているか確かめてから、もう一度手順 2 を押す。 |
| 「Run workflow」のボタンが見当たらない | GitHub にログインしているか確かめる。ページを読み込み直す。 |

## 知っておくこと

- 「表示しない」にしても、ジャンルの作品数と「全○作品」には、その小分類の作品も含めます。
- 毎月5日の「毎月の作品データ更新」でも、表示設定は自動で反映されます。kintone で直したまま反映を忘れても、遅くとも次の5日には反映されます。
- 自動で反映するのは毎月5日だけです。すぐに反映したいときは手順 2 を押してください。
- `data/display.js` は自動で書き換わるファイルです。手で直さないでください。
- いま隠している小分類は、アプリ513 の一覧で「表示」が「表示しない」の行です。毎月の [`data/check.md`](../data/check.md) の「表示しない小分類」にも出ます。

## はじめに1回だけやること（アプリの用意）

2026-10-20 にすべて済んでいます（アプリ513 の作成、89件の登録、API トークン、GitHub のシークレット）。ここは、作り直すときやトークンを作り直すときのための記録です。

### 1. アプリを作る

kintone で「はじめから作成」を選び、名前を「小分類の表示設定」にして、次の項目を置きます。**フィールドコード**は表のとおりにしてください（自動更新はフィールドコードで読みます）。

| 項目名 | 種類 | フィールドコード | 設定 |
|---|---|---|---|
| 小分類コード | 文字列（1行） | `小分類コード` | 必須、値の重複を禁止 |
| 小分類名 | 文字列（1行） | `小分類名` | 参考用 |
| ジャンル | 文字列（1行） | `ジャンル` | 参考用 |
| 表示 | ラジオボタン（ドロップダウンでも可） | `表示` | 選択肢は「表示する」「表示しない」、初期値は「表示する」 |
| メモ | 文字列（複数行） | `メモ` | 表示しない理由など |

一覧は「ジャンル」「小分類コード」の順に並べると見やすくなります。

### 2. 89件を取り込む

アプリの一覧画面 →「…」→「ファイルから読み込む」で `小分類の表示設定_初期データ.csv` を取り込みます（文字コードは UTF-8、先頭行を項目名にする）。最初はすべて「表示する」です。

### 3. API トークンを作る

アプリの設定 →「API トークン」で、**「レコード閲覧」だけ**にチェックしたトークンを作り、アプリを更新します。

### 4. GitHub にシークレットを2つ登録する

GitHub のリポジトリ →「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で登録します。

| Name | Secret |
|---|---|
| `KINTONE_DISPLAY_APP` | アプリの番号（アプリを開いたときの URL の `/k/` のあとの数字） |
| `KINTONE_TOKEN_DISPLAY` | 3 で作った API トークン |

登録したら「Run workflow」で一度動かし、`data/check.md` の「表示しない小分類」が「ありません。」になっていれば準備完了です。

## 小分類を増やしたり名前を変えたりしたとき

`genres_config.json` と 507 の選択肢を直したら、このアプリにも同じ小分類コードの行を足してください（行が無い小分類は「表示する」として扱います）。
