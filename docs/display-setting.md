# 小分類の表示設定

ページに出したくない小分類を、kintone のアプリ513「小分類の表示設定」で「表示しない」にできます。GitHub の「**小分類の表示設定を反映**」を手動で動かすと、1分ほどで反映されます（自動では動きません）。毎月5日の作品データ更新のときにも反映されます。

- 「表示しない」にした小分類は、目次にもジャンルのページにも出ません。
- その小分類だけに入っている作品は、ページに出なくなります。主か副にほかの小分類があれば、そちらには出ます。
- ジャンルの作品数と「全○作品」には、表示しない小分類の作品も含めます。
- 1つのジャンルの小分類をすべて「表示しない」にすると、そのジャンルも目次に出なくなります。
- アプリが読めないとき（トークンの誤りなど）は、更新を止めます。ページは前の状態のままです。
- いま隠している小分類は、アプリ513 の一覧で「表示」が「表示しない」の行です。ページに反映済みのものは [`data/display.js`](../data/display.js) に、毎月の更新の時点のものは [`data/check.md`](../data/check.md) の「表示しない小分類」に出ます。
- 前に開いたことがある人には、反映後も10分ほど前の表示が出ることがあります。

## 切り替え方

1. アプリ513「小分類の表示設定」で、その小分類の「表示」を「表示しない」（戻すときは「表示する」）にして保存します。
2. GitHub の「Actions」→「**小分類の表示設定を反映**」→「Run workflow」を押します。
3. 1分ほどで緑のチェックになれば、ページに反映されています。

「小分類の表示設定を反映」はアプリ513 だけを読み、作品データ（402・507 など）には触りません。作品データも一緒に作り直したいときは、「毎月の作品データ更新」を動かします（表示設定も一緒に反映されます）。

## はじめに1回だけやること（アプリの用意）

アプリは **アプリ513「小分類の表示設定」**（507 と同じスペース）として作成済みで、89件も登録済みです（2026-10-20）。残っているのは「3. API トークンを作る」と「4. GitHub にシークレットを2つ登録する」です。1・2 は、作り直すときのための記録です。

### 1. アプリを作る

kintone で「はじめから作成」を選び、名前を「小分類の表示設定」にして、次の項目を置きます。**フィールドコード**は表のとおりにしてください（自動更新はフィールドコードで読みます）。

| 項目名 | 種類 | フィールドコード | 設定 |
|---|---|---|---|
| 小分類コード | 文字列（1行） | `小分類コード` | 必須、値の重複を禁止 |
| 小分類名 | 文字列（1行） | `小分類名` | 参考用 |
| ジャンル | 文字列（1行） | `ジャンル` | 参考用 |
| 表示 | ラジオボタン | `表示` | 選択肢は「表示する」「表示しない」、初期値は「表示する」 |
| メモ | 文字列（複数行） | `メモ` | 表示しない理由など |

一覧は「ジャンル」「小分類コード」の順に並べると見やすくなります。

### 2. 89件を取り込む

アプリの一覧画面 →「…」→「ファイルから読み込む」で `小分類の表示設定_初期データ.csv` を取り込みます（文字コードは UTF-8、先頭行を項目名にする）。最初はすべて「表示する」です。

### 3. API トークンを作る

アプリの設定 →「API トークン」で、**「レコード閲覧」だけ**にチェックしたトークンを作り、アプリを更新します。

### 4. GitHub にシークレットを2つ登録する

GitHub のリポジトリ →「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で登録します。

| Name | Secret |
|---|---|
| `KINTONE_DISPLAY_APP` | アプリの番号（アプリを開いたときの URL の `/k/` のあとの数字） |
| `KINTONE_TOKEN_DISPLAY` | 3 で作った API トークン |

登録したら「Run workflow」で一度動かし、`data/check.md` の「表示しない小分類」が「ありません。」になっていれば準備完了です。

## 小分類を増やしたり名前を変えたりしたとき

`genres_config.json` と 507 の選択肢を直したら、このアプリにも同じ小分類コードの行を足してください（行が無い小分類は「表示する」として扱います）。
